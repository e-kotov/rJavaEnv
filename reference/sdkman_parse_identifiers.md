# Parse SDKMAN identifiers into structured data frame

Parse SDKMAN identifiers into structured data frame

## Usage

``` r
sdkman_parse_identifiers(identifiers, platform, arch)
```

## Arguments

- identifiers:

  Character vector of SDKMAN identifiers (e.g., "21.0.12-amzn")

- platform:

  Platform OS

- arch:

  Architecture

## Value

data.frame with standard columns
